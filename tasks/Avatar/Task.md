# Person CV Task

## Ziel

Lass uns ein Testing-Sezenario bauen um eine Person zu erstellen

## Anforderungen

- Die person hat einen Lebenslauf,
  in dem Ordner unter @tasks/Avatar/CV.md zu finden sind,
  Baue eine kurze Beispiel-CV Datei
- Baue ein Beispiel Chat-Szenario, die Fragen an die Person stellt
- Nutze die Informationen aus dem Lebenslauf um die Antworten zu generieren
- Test 1: die Antwort wird ist im CV.md zu finden
  -> Antwort wird gegeben
- Test 2: die Antwort ist nicht im CV.md zu finden
  -> Antwort: "Das weiss ich leider nicht"
